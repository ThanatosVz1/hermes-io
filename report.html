Abstract :

Hermes.io is an autonomous, full-stack educational intelligence platform designed to address the fragmentation, static rigidity, and absence of verified progress in modern self-directed technical education. Built upon a unified Node.js serverless HTTP micro-engine and backed by a resilient dual-tier persistence architecture utilizing Supabase PostgreSQL with zero-loss local JSON file failover, Hermes synthesizes personalized, role-specific curriculum trees utilizing modern Large Language Model (LLM) inference. The platform incorporates multi-tiered learning modalities, offering both an intelligent 4-step customization wizard and a curated gallery of standardized industry blueprints. Each generated curriculum features an interactive, recursive milestone constellation with on-demand submodule expansions, verified knowledge mastery quizzes, and an executive Hermes Overseer Terminal secured via stateless cryptographic HMAC-SHA256 tokens. Interactive features include procedural celestial planet avatars, a cosmic living universe canvas with slow-falling shooting stars, and a tactile Slide to Enter gateway. Rigorous automated verification demonstrates sub-15ms telemetry latency, seamless offline fallback, and high-fidelity progress synchronization across distributed serverless environments.

1. Introduction

1.1 Project Overview & Motivation

The rapid proliferation of web and software frameworks has rendered self-directed technical education indispensable yet increasingly overwhelming. Aspiring software engineers and industry practitioners navigate thousands of disparate tutorials, documentation pages, and video courses. Without structured milestones, workload calibration, and objective evaluations, learners frequently experience tutorial paralysis and abandon their goals.

The Hermes.io project engineers an end-to-end curriculum synthesizer, interactive progress tracker, and administrative observability platform. By marrying generative artificial intelligence with modern reactive web interfaces, Hermes converts broad career aspirations (e.g., Full-Stack Engineer, Machine Learning Specialist, DevOps Architect) into clear, actionable milestone constellations accompanied by study hour estimates, hands-on project briefs, and modular mastery assessments.

1.2 Problem Statement & Industry Context

Existing educational platforms exhibit several critical bottlenecks:

  • Disjointed Learning Resources — Learners spend excessive hours aggregating tutorials across heterogeneous blogs and video repositories without clear sequencing or prerequisite validation.
  • Static, Non-Adaptive Roadmaps — Conventional roadmap websites provide static PNG or SVG infographics that cannot adapt to an individual's background, available hours, or tech-stack preferences.
  • Absence of Verified Comprehension — Traditional roadmap platforms rely entirely on unverified self-checking, providing no objective mechanism to confirm whether a learner truly understood core concepts.
  • Administrative Blind Spots in Teams — Mentors, instructors, and team supervisors lack unified telemetry into learner progression, struggle points, and examination pass rates.

1.3 Project Scope & Key Objectives

To eliminate these bottlenecks, Hermes.io fulfills the following engineering objectives:

  1. Immersive Visual Presentation — Implement a cosmic living universe theme with slow-falling shooting stars, a tactile Slide to Enter gate, and procedural SVG celestial star/planet avatars.
  2. Intelligent Curriculum Synthesis — Orchestrate Google Gemini LLM inference with structured JSON schemas to dynamically generate multi-tier milestone trees with automatic offline fallback.
  3. Recursive Submodule Expansion — Allow learners to dynamically unpack high-level nodes into concrete, sub-milestone task graphs on demand.
  4. Automated Knowledge Mastery Verification — Provide built-in, modular 10-question mastery examinations with automated grading, time logging, and tiered certification pills.
  5. Stateless Cryptographic Security — Construct the Hermes Overseer Terminal secured with stateless HMAC-SHA256 tokens designed for serverless lambda environments.
  6. Dual-Tier Persistent Storage — Combine Supabase PostgreSQL cloud persistence with automatic local filesystem JSON synchronization for complete offline continuity.

2. Tools and Technologies

2.1 Frontend Architecture & Custom Design System

The client interface is engineered using semantic HTML5, modern CSS3 custom properties (CSS variables), and modular vanilla JavaScript (ESNext). By avoiding the overhead of heavy single-page application frameworks, Hermes achieves instant first-contentful-paint (FCP), zero build-step overhead, and smooth 60fps animations.

  • Phosphor Icons Web (v2.1.1) — Comprehensive iconography across regular and fill states.
  • Typography — Plus Jakarta Sans for headings and UI copy; JetBrains Mono for code, telemetry, and tokens; Times New Roman for formal academic publication styling.
  • Celestial Avatars Engine — Deterministic procedural SVG generator producing 10 unique planetary and star archetypes seeded by user email addresses.

2.2 Serverless Micro-Engine & REST API Layer

The backend is powered by native Node.js utilizing standard library modules without external web framework dependencies.

  • Stateless HTTP Server — Lightweight RESTful micro-engine handling CORS, streaming JSON bodies, static asset caching, and security headers.
  • Stateless Cryptographic HMAC-SHA256 Auth — Eliminates fragile in-memory session stores by issuing signed bearer tokens (hadmin.<payload>.<signature>) that remain valid across distributed, ephemeral serverless lambda containers.

2.3 Cloud Persistence & Dual-Tier Failover

  • Supabase PostgreSQL (v15) — Cloud relational database managing persistent tables for users, sessions, roadmaps, quiz_results, and app_config.
  • Local JSON Failover — Autonomous filesystem persistence layer (data/users.json, data/roadmaps.json, data/quiz_results.json) guaranteeing 100% functional continuity during cloud outages or zero-configuration development.

2.4 AI Model Orchestration & Infrastructure

  • Google Gemini API (Gemini 2.5 Flash) — High-speed JSON schema generation for curriculum structuring, milestone sequencing, and contextual quiz formulation.
  • Vercel Serverless Edge — Continuous deployment pipeline with automated Git push triggering.

4. Implementation Methodology

4.1 Tactile Cosmic Splash Gateway & Gestural Physics

The entry experience features a full-viewport, zero-dependency cosmic splash page. The interface displays an astronomical planetary core with rotating dashed orbital rings, a slow shooting star particle animation, and the subtitle powered by thanatosvz.

To deliver an engaging tactile entry mechanic, a physics-inspired Slide to Enter slider is implemented. The user drags a glowing celestial thumb across an obsidian pill track. As dragging progresses, the label opacity dynamically diminishes:

Opacity(x) = max(0, 1 - 1.5 * (x / x_max))

Upon crossing the 70% displacement threshold (x ≥ 0.70 * x_max), the control snaps to completion, displays an emerald checkmark, triggers a warp blur transition, and dissolves into the main workspace.

4.2 Seeded Celestial Planet & Star Avatar Algorithm

To avoid impersonal default profile avatars, Hermes generates personalized procedural vector avatars using the learner's email address as an entropy seed. A polynomial rolling hash algorithm deterministically assigns celestial archetypes:

Hash = Σ (s[i] * 31^(n-1-i)) mod 2^32

The derived integer seeds 8 distinct celestial color palettes, planetary ring orbital inclinations, and twinkling background stellar fields rendered as standalone SVG elements.

4.3 Stateless Cryptographic HMAC-SHA256 Overseer Security Architecture

Traditional stateful in-memory sessions fail in serverless cloud environments (e.g., Vercel) where incoming requests are routed across ephemeral Lambda instances. Hermes resolves this using cryptographic HMAC-SHA256 tokens:

Token = "hadmin." + Base64Url(Payload) + "." + HMAC-SHA256(Base64Url(Payload), K_secret)

Every serverless instance cryptographically verifies token integrity and expiration without querying shared database memory, completely eliminating 401 session-loss anomalies.

4.4 Modular Knowledge Verification & Examination Engine

Each curriculum milestone links directly to an automated knowledge verification modal. The system evaluates answers, aggregates percentage scores, stores completion timestamps, and renders color-coded mastery pills (Mastered ≥ 80%, Passed ≥ 60%, Review Required < 60%).

7.2 Bug Fix and Refactoring Log

  • Vercel Serverless Session Loss — Symptom: Admin dashboard returned 401 Unauthorized after navigating across pages on Vercel. Root Cause: Memory Map was partitioned across serverless lambdas. Fix: Replaced with stateless HMAC-SHA256 signature tokens.
  • Gate Error Flashing on Initial Load — Symptom: "Access Denied" error was visible before credentials were typed. Root Cause: Conflicting display: none and display: flex in inline styles. Fix: Enforced CSS class hierarchy with clean input listeners.
  • AI Loading Overlay Layout Inversion — Symptom: Status copy rendered awkwardly beneath animated GIF. Fix: Reordered flex column layout so pulsating status text renders directly above the GIF with a 2-second minimum duration.
  • Settings Modal Input Sanitization — Symptom: Supabase Cloud Database options cluttered the user interface when developers only needed to supply Gemini or Claude API keys. Fix: Refactored settings modal to exclusively present AI API keys with graceful error handling.
