\noindent{\Large\bfseries Abstract :}\\
\vspace{2pt}
\begin{abstractbox}
\noindent
\textbf{Hermes.io} is an autonomous, full-stack educational intelligence platform designed to address the fragmentation, static rigidity, and absence of verified progress in modern self-directed technical education. Built upon a unified \texttt{Node.js} serverless HTTP micro-engine and backed by a resilient dual-tier persistence architecture utilizing \textbf{Supabase PostgreSQL} with zero-loss local JSON file failover, Hermes synthesizes personalized, role-specific curriculum trees utilizing modern \textbf{Large Language Model (LLM)} inference. The platform incorporates multi-tiered learning modalities, offering both an intelligent 4-step customization wizard and a curated gallery of standardized industry blueprints. Each generated curriculum features an interactive, recursive milestone constellation with on-demand submodule expansions, verified knowledge mastery quizzes, and an executive \textbf{Hermes Overseer Terminal} secured via stateless cryptographic \texttt{HMAC-SHA256} tokens. Interactive features include procedural celestial planet avatars, a cosmic living universe canvas with slow-falling shooting stars, and a tactile \textbf{Slide to Enter} gateway. Rigorous automated verification demonstrates sub-15ms telemetry latency, seamless offline fallback, and high-fidelity progress synchronization across distributed serverless environments.
\end{abstractbox}

\section{Introduction}

\subsection{Project Overview \& Motivation}
The rapid proliferation of web and software frameworks has rendered self-directed technical education indispensable yet increasingly overwhelming. Aspiring software engineers and industry practitioners navigate thousands of disparate tutorials, documentation pages, and video courses. Without structured milestones, workload calibration, and objective evaluations, learners frequently experience tutorial paralysis and abandon their goals. 

The \textbf{Hermes.io} project engineers an end-to-end curriculum synthesizer, interactive progress tracker, and administrative observability platform. By marrying generative artificial intelligence with modern reactive web interfaces, Hermes converts broad career aspirations (e.g., \textit{Full-Stack Engineer}, \textit{Machine Learning Specialist}, \textit{DevOps Architect}) into clear, actionable milestone constellations accompanied by study hour estimates, hands-on project briefs, and modular mastery assessments.

\subsection{Problem Statement \& Industry Context}
Existing educational platforms exhibit several critical bottlenecks:
\begin{itemize}[leftmargin=1.5em, itemsep=6pt]
    \item \textbf{Disjointed Learning Resources} -- Learners spend excessive hours aggregating tutorials across heterogeneous blogs and video repositories without clear sequencing or prerequisite validation.
    \item \textbf{Static, Non-Adaptive Roadmaps} -- Conventional roadmap websites provide static PNG or SVG infographics that cannot adapt to an individual's background, available hours, or tech-stack preferences.
    \item \textbf{Absence of Verified Comprehension} -- Traditional roadmap platforms rely entirely on unverified self-checking, providing no objective mechanism to confirm whether a learner truly understood core concepts.
    \item \textbf{Administrative Blind Spots in Teams} -- Mentors, instructors, and team supervisors lack unified telemetry into learner progression, struggle points, and examination pass rates.
\end{itemize}

\subsection{Project Scope \& Key Objectives}
To eliminate these bottlenecks, Hermes.io fulfills the following engineering objectives:
\begin{enumerate}[leftmargin=1.5em, itemsep=4pt]
    \item \textbf{Immersive Visual Presentation} -- Implement a cosmic living universe theme with slow-falling shooting stars, a tactile \textit{Slide to Enter} gate, and procedural SVG celestial star/planet avatars.
    \item \textbf{Intelligent Curriculum Synthesis} -- Orchestrate Google Gemini LLM inference with structured JSON schemas to dynamically generate multi-tier milestone trees with automatic offline fallback.
    \item \textbf{Recursive Submodule Expansion} -- Allow learners to dynamically unpack high-level nodes into concrete, sub-milestone task graphs on demand.
    \item \textbf{Automated Knowledge Mastery Verification} -- Provide built-in, modular 10-question mastery examinations with automated grading, time logging, and tiered certification pills.
    \item \textbf{Stateless Cryptographic Security} -- Construct the \textbf{Hermes Overseer Terminal} secured with stateless \texttt{HMAC-SHA256} tokens designed for serverless lambda environments.
    \item \textbf{Dual-Tier Persistent Storage} -- Combine Supabase PostgreSQL cloud persistence with automatic local filesystem JSON synchronization for complete offline continuity.
\end{enumerate}

\section{Tools and Technologies}

\subsection{Frontend Architecture \& Custom Design System}
The client interface is engineered using semantic \texttt{HTML5}, modern \texttt{CSS3} custom properties (CSS variables), and modular vanilla \texttt{JavaScript (ESNext)}. By avoiding the overhead of heavy single-page application frameworks, Hermes achieves instant first-contentful-paint (FCP), zero build-step overhead, and smooth 60fps animations.
\begin{itemize}[leftmargin=1.5em, itemsep=4pt]
    \item \textbf{Phosphor Icons Web (v2.1.1)} -- Comprehensive iconography across regular and fill states.
    \item \textbf{Typography} -- \textit{Plus Jakarta Sans} for headings and UI copy; \textit{JetBrains Mono} for code, telemetry, and tokens; \textit{Times New Roman} for formal academic publication styling.
    \item \textbf{Celestial Avatars Engine} -- Deterministic procedural SVG generator producing 10 unique planetary and star archetypes seeded by user email addresses.
\end{itemize}

\subsection{Serverless Micro-Engine \& REST API Layer}
The backend is powered by native \texttt{Node.js} utilizing standard library modules without external web framework dependencies.
\begin{itemize}[leftmargin=1.5em, itemsep=4pt]
    \item \textbf{Stateless HTTP Server} -- Lightweight RESTful micro-engine handling CORS, streaming JSON bodies, static asset caching, and security headers.
    \item \textbf{Stateless Cryptographic HMAC-SHA256 Auth} -- Eliminates fragile in-memory session stores by issuing signed bearer tokens (\texttt{hadmin.<payload>.<signature>}) that remain valid across distributed, ephemeral serverless lambda containers.
\end{itemize}

\subsection{Cloud Persistence \& Dual-Tier Failover}
\begin{itemize}[leftmargin=1.5em, itemsep=4pt]
    \item \textbf{Supabase PostgreSQL (v15)} -- Cloud relational database managing persistent tables for \texttt{users}, \texttt{sessions}, \texttt{roadmaps}, \texttt{quiz\_results}, and \texttt{app\_config}.
    \item \textbf{Local JSON Failover} -- Autonomous filesystem persistence layer (\texttt{data/users.json}, \texttt{data/roadmaps.json}, \texttt{data/quiz\_results.json}) guaranteeing 100\% functional continuity during cloud outages or zero-configuration development.
\end{itemize}

\subsection{AI Model Orchestration}
\begin{itemize}[leftmargin=1.5em, itemsep=4pt]
    \item \textbf{Google Gemini API (Gemini 2.5 Flash)} -- High-speed JSON schema generation for curriculum structuring, milestone sequencing, and contextual quiz formulation.
    \item \textbf{Vercel Serverless Edge} -- Continuous deployment pipeline with automated Git push triggering.
\end{itemize}

\section{Implementation Methodology}

\subsection{Tactile Cosmic Splash Gateway \& Gestural Physics}
The entry experience features a full-viewport, zero-dependency cosmic splash page. The interface displays an astronomical planetary core with rotating dashed orbital rings, a slow shooting star particle animation, and the subtitle \textit{powered by thanatosvz}. 

To deliver an engaging tactile entry mechanic, a physics-inspired \textbf{Slide to Enter} slider is implemented. The user drags a glowing celestial thumb across an obsidian pill track. As dragging progresses, the label opacity dynamically diminishes:
\begin{equation}
\text{Opacity}(x) = \max\left(0, 1 - 1.5 \cdot \frac{x}{x_{\max}}\right)
\end{equation}
Upon crossing the 70\% displacement threshold ($x \ge 0.70 \cdot x_{\max}$), the control snaps to completion, displays an emerald checkmark, triggers a warp blur transition, and dissolves into the main workspace.

\subsection{Seeded Celestial Planet \& Star Avatar Generation Algorithm}
To avoid impersonal default profile avatars, Hermes generates personalized procedural vector avatars using the learner's email address as an entropy seed. A polynomial rolling hash algorithm deterministically assigns celestial archetypes:
\begin{equation}
H = \sum_{i=0}^{n-1} s[i] \cdot 31^{n-1-i} \pmod{2^{32}}
\end{equation}
The derived integer seeds 8 distinct celestial color palettes, planetary ring orbital inclinations, and twinkling background stellar fields rendered as standalone SVG elements.

\subsection{Stateless Cryptographic HMAC-SHA256 Overseer Security Architecture}
Traditional stateful in-memory sessions fail in serverless cloud environments (e.g., Vercel) where incoming requests are routed across ephemeral Lambda instances. Hermes resolves this using cryptographic \texttt{HMAC-SHA256} tokens:
\begin{equation}
\text{Token} = \texttt{hadmin.} \parallel \text{Base64Url}(\text{Payload}) \parallel \texttt{.} \parallel \text{HMAC-SHA256}(\text{Base64Url}(\text{Payload}), K_{\text{secret}})
\end{equation}
Every serverless instance cryptographically verifies token integrity and expiration without querying shared database memory, completely eliminating 401 session-loss anomalies.

\subsection{Modular Knowledge Verification \& Examination Engine}
Each curriculum milestone links directly to an automated knowledge verification modal. The system evaluates answers, aggregates percentage scores, stores completion timestamps, and renders color-coded mastery pills (\textit{Mastered} $\ge 80\%$, \textit{Passed} $\ge 60\%$, \textit{Review Required} $< 60\%$).

    enterSite(); // Triggers warp dissolve transition

function signAdminToken(adminData) {
  const payload = {
    email: adminData.email,
    name: 'Cronus (Overseer)',
    role: 'administrator',
    iat: Date.now(),
    exp: Date.now() + (30 * 24 * 60 * 60 * 1000) // 30-day validity
  };
  const body = Buffer.from(JSON.stringify(payload)).toString('base64url');
  const sig = crypto.createHmac('sha256', ADMIN_SECRET)
                    .update(body).digest('base64url');
  return `hadmin.${body}.${sig}`;
}

function verifyAdminToken(token) {
  if (!token || !token.startsWith('hadmin.')) return null;
  const [prefix, body, sig] = token.split('.');
  const expectedSig = crypto.createHmac('sha256', ADMIN_SECRET)
                            .update(body).digest('base64url');
  if (sig !== expectedSig) return null;
  const payload = JSON.parse(Buffer.from(body, 'base64url').toString('utf8'));
  return Date.now() <= payload.exp ? payload : null;
}
\end{lstlisting}

function generatePlanetAvatar(seed) {
  let hash = 0;

  }
  const palettes = [
    { p: '#F97316', r: '#FDBA74', bg: '#431407' }, // Solar Orange

    { p: '#10B981', r: '#6EE7B7', bg: '#064E3B' }  // Emerald Terra
  ];
  const choice = palettes[Math.abs(hash) % palettes.length];
  const hasRing = (Math.abs(hash) % 2) === 0;
  return `<svg viewBox="0 0 100 100" class="planet-avatar">
    <circle cx="50" cy="50" r="48" fill="${choice.bg}"/>
    <circle cx="50" cy="50" r="24" fill="${choice.p}"/>
    ${hasRing ? `<ellipse cx="50" cy="50" rx="38" ry="12" fill="none" stroke="${choice.r}" stroke-width="4" transform="rotate(-25 50 50)"/>` : ''}
  </svg>`;
}

\subsection{Bug Fix and Refactoring Log}
\begin{itemize}[leftmargin=1.5em, itemsep=5pt]
    \item \textbf{Vercel Serverless Session Loss} -- \textit{Symptom:} Admin dashboard returned 401 Unauthorized after navigating across pages on Vercel. \textit{Root Cause:} Memory \texttt{Map} was partitioned across serverless lambdas. \textit{Fix:} Replaced with stateless HMAC-SHA256 signature tokens.
    \item \textbf{Gate Error Flashing on Initial Load} -- \textit{Symptom:} "Access Denied" error was visible before credentials were typed. \textit{Root Cause:} Conflicting \texttt{display: none} and \texttt{display: flex} in inline styles. \textit{Fix:} Enforced CSS class hierarchy with clean input listeners.
    \item \textbf{AI Loading Overlay Layout Inversion} -- \textit{Symptom:} Status copy rendered awkwardly beneath animated GIF. \textit{Fix:} Reordered flex column layout so pulsating status text renders directly above the GIF with a 2-second minimum duration.
    \item \textbf{Settings Modal Input Sanitization} -- \textit{Symptom:} Supabase Cloud Database options cluttered the user interface when developers only needed to supply Gemini or Claude API keys. \textit{Fix:} Refactored settings modal to exclusively present AI API keys with graceful error handling.
\end{itemize}
